## 🌟 About the Project

**Hangman: Modern AI Edition** is a clean, accessible, and fun word-guessing web application built with **Python & Streamlit**. It is designed so that **anyone**—from casual gamers to tech recruiters—can immediately play, have fun, and interact with an integrated **AI Assistant (NEXUS AI)**.

```
       +---+
       |   |
       O   |      Lives: ❤️ ❤️ ❤️ ❤️ 🖤 🖤
      /|\  |      Word:  P Y T H _ N
      /    |
    =========
```

---

## ✨ Features That Make It Special

### 1. 🤖 Embedded 24/7 AI Helper (NEXUS AI)
- **Always Friendly**: Gives helpful, easy-to-understand hints if you get stuck on a word.
- **Interactive Chat**: Answers questions about how to play, word meanings, and developer background.
- **Instant Shortcuts**: One-click buttons for `💡 Get a Hint`, `🎮 How to Play`, `👨‍💻 Developer Profile`, and `🧹 Clear Chat`.

### 2. 🎨 Clean, Non-Technical User Interface
- **Visual Hangman Drawing**: Real-time classic gallows drawing showing progress as letters are guessed.
- **Heart Lives Bar**: Visual `❤️ ❤️ ❤️ ❤️ ❤️ ❤️` display that makes lives crystal clear.
- **Virtual A-Z Keyboard**: Tap-friendly letter buttons that turn green (`✓`) for correct guesses and dim (`✗`) for misses.
- **Winning Streak & Score**: Tracks how many words you have solved in a row!

### 3. 📚 Fun Everyday Word Categories
- 💻 **Tech & AI**: *Python, Robot, Computer, Internet, Chatbot, Coding...*
- 🦁 **Animals**: *Elephant, Dolphin, Tiger, Giraffe, Penguin, Kangaroo...*
- 🌍 **Countries**: *Pakistan, Turkey, Japan, Canada, Brazil, Germany, Egypt...*
- 🎬 **Movies & Fun**: *Avatar, Titanic, Inception, Gladiator, Frozen, Batman...*

---

## 🎮 How to Play

1. **Pick a Category**: Select from Tech, Animals, Countries, or Movies.
2. **Guess Letters**: Click any letter on the on-screen keypad.
3. **Keep Your Lives**: You have **6 hearts ❤️**. Each wrong guess takes 1 heart.
4. **Win the Game**: Reveal the complete word before running out of hearts!
5. **Ask for Help**: If you get stuck, ask **NEXUS AI** in the sidebar for a friendly hint.

## 🚀 Quick Start (Run Locally)

```bash
# 1. Clone the repository
git clone https://github.com/SainBux-HadiSeelro/Agentic-Hangman-2.0.git
cd Agentic-Hangman-2.0

# 2. Install requirements
pip install -r requirements.txt

# 3. Launch application
streamlit run app.py
```

Then open `http://localhost:8501` in your browser!
